# Developer Environment Foundation

Phase 0 — Developer Setup Repository for AI & Machine Learning.

## Overview
This repository sets up the baseline developer workflow including:
- Python virtual environment (`.venv`)
- VS Code workspace & tooling
- PowerShell execution environment
- Git version control & GitHub integration

## Quickstart

1. **Activate Virtual Environment:**
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

2. **Run main script:**
   ```powershell
   python main.py
   ```
